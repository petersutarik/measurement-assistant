# Measurement Assistant

AI-powered SaaS for dataLayer implementation documentation and marketing measurement plans.

## Tech Stack

- **Framework:** Next.js 15 (App Router) with TypeScript
- **Styling:** Tailwind CSS v4 + shadcn/ui
- **Database:** PostgreSQL (Supabase) with Drizzle ORM
- **Validation:** Zod

## Project Structure

```
src/
  app/           — Next.js App Router pages and layouts
    api/         — REST API routes
  components/
    ui/          — shadcn/ui components
  lib/
    auth/        — Auth helpers
    db/
      schema/    — Drizzle schema files
    utils.ts     — shadcn/ui utility (cn)
    validators/  — Zod validation schemas
  types/         — TypeScript types (derived from Drizzle)
supabase/
  migrations/    — SQL migrations (generated by drizzle-kit)
```

## Commands

```bash
npm run dev          # Start dev server (Turbopack)
npm run build        # Production build
npm run lint         # ESLint
npm run format       # Prettier
npm run db:generate  # Generate migrations from schema
npm run db:migrate   # Run migrations
npm run db:push      # Push schema directly (dev)
npm run db:studio    # Open Drizzle Studio
```

## Conventions

- Use `@/` import alias for all project imports
- Drizzle schema files go in `src/lib/db/schema/` and are re-exported from `index.ts`
- Zod validators go in `src/lib/validators/`
- Types derived from Drizzle use `InferSelectModel` in `src/types/`
- Use shadcn/ui components via `npx shadcn@latest add <component>`
- Environment variables: copy `.env.example` to `.env.local`
